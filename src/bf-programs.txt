OpenLab 2026 笔试 · 第 7 题「魔术书」作答源码
==============================================
语言：Brainfuck
约定：每个格子初始 0，取值 0-255 回绕；指针初始指向 cell0。

--------------------------------------------------------------
题 1  题目给定程序（用于观察，不修改）
--------------------------------------------------------------
,[ >+ <-] >-.

预期行为：输出输入字符的 ASCII 码 - 1。
  'A'(65) -> '@'(64)
  'Z'(90) -> 'Y'(89)
  'b'(98) -> 'a'(97)
题面注释「读入一个字符，若该字符不为 0 则输出该字符」是错误的。


--------------------------------------------------------------
题 2  题目给定程序（用于观察，不修改）
--------------------------------------------------------------
++++++++++ [ >++++++++ >++++++++ <<-] >-. >.

预期行为：输出 "OP"
  10 次循环 x 每次 +8 = 80
  cell1 = 80 -> 减 1 = 79 -> 'O'
  cell2 = 80 -> 'P'


--------------------------------------------------------------
题 3  我的解答：读入两个字符，输出其 ASCII 码之和对应的字符
--------------------------------------------------------------
,>,<[->+<]>.

拆解：
  ,       读第 1 个字符 -> cell0
  >       指针移到 cell1
  ,       读第 2 个字符 -> cell1
  <       回 cell0
  [->+<]  搬运循环：cell0-1 同时 cell1+1，直到 cell0 归零 -> cell1 = a+b
  >       移到 cell1
  .       输出

验证用例（结果为 (a+b) mod 256，格子自动回绕）：
  输入 'A' '!'  -> 65+33 = 98   -> 'b'
  输入 '0' ' '  -> 48+32 = 80   -> 'P'
  输入 'A' 'Z'  -> 65+90 = 155  -> 不可打印字符
  输入 'Z' 'Z'  -> 90+90 = 180  -> 不可打印字符
